## Installation

To set up the project locally, follow these steps:

### **Prerequisites**

Make sure you have the following installed:

- [Node.js](https://nodejs.org/) (v20 or higher) 📦  
- [Git](https://git-scm.com/) 🔧

### **Project Setup**

1. **Clone the repository:**

   ```bash
   git clone https://github.com/Zeteox/portfolio.git
   cd portfolio
   ```

2. **Install dependencies:**

   ```bash
   npm install --force
   ```

3. **Start the project**

   ```bash
   npm run dev #start the project in mode dev
   npm run build #build the project
   npm run start #start the builded project
   ```
